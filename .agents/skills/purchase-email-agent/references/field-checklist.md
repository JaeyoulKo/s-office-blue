# 필수 정보 체크리스트

사용할 수 없는 값은 `unknown`으로 둔다. 필드는 해당 유형의 검토에 실질적으로 필요한 경우에만 필수로 취급한다. 값의 출처는 사용자 제공 자료 또는 사용 가능한 읽기 전용 MCP Tool 결과로 기록하며, MCP Tool이 없으면 값을 추정하지 않는다.

| 이메일 유형 | 일반적으로 검토에 필요한 정보 | 조건부 정보 |
| --- | --- | --- |
| 구매 요청 | 품목/서비스, 구매 목적, 공급사, 금액·통화, 수량/범위, 필요 납기 | 계약 기간, 견적서, 예산/코스트센터, 기대효과, 요청자/담당자 |
| 구매 승인 요청 | 요청된 승인/작업, 품목/서비스, 공급사, 금액/통화, 목적, 요청자, 명시된 승인 기한 | 수량, 납기, 계약 기간, 견적서, 기대효과 근거, 위험/예외 사유 |
| 계약 관련 | 계약 당사자/공급사, 대상, 요청된 계약 작업, 기간, 관련 시 금액/가격, 핵심 조건 | 납기/서비스 수준, 갱신/해지, 조건 예외, 승인자/담당자 |
| 보완 요청 또는 질의 | 질문/요청, 관련 요청 식별자 또는 문맥, 담당자, 명시된 회신 시점 | 답변에 필요한 원 구매/계약 필드 |
| 공지 / 일반 업무 이메일 | 메시지 목적, 요청 작업(있는 경우) | 실제 구매 관련성이 생긴 경우에만 구매 필드 |

누락된 적용 대상 필드마다 (1) 누락 항목, (2) 검토 제한 이유, (3) 구체적 확인 질문, (4) 요청자 정보가 아닌 사용자 판단이 필요한지 여부를 기록한다.
