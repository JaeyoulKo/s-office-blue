# Office Blue 이메일 분류 체계

- `구매 승인 검토 필요 이메일`: 구매, 지출 또는 Ariba 작업의 승인을 명시적으로 요청한다.
- `논의 내용 요약 필요 이메일`: 계약, 구매 또는 지출 건의 변경, 조건, 상태, 쟁점이나 다음 결정을 논의한다.
- `일반 이메일`: 위 두 유형이 아닌 업무 메일이다. 공지, 단순 안내, 이미 처리된 건의 정정·재제출 사실 통보를 포함한다.

한 번의 A/B 비교에서는 이 taxonomy의 동일한 내용을 두 조건에 제공한다.

이미 승인된 PR의 오기입을 바로잡아 재제출했다는 안내처럼, 새로운 구매나 승인을 요청하지 않고 정정 사실만 전달하는 메일은 `일반 이메일`로 분류한다. 제목이나 본문에 PR, 승인, 재제출이 포함되어 있어도 그 단어만으로 `구매 승인 검토 필요 이메일`로 분류하지 않는다.

단일 라벨이 겹치면 전체 스레드의 변경 이력을 먼저 본다. 스레드 도중 금액, Vendor, Scope 또는 주요 계약 조건의 이전 값과 최신 값이 실제로 달라졌다면, 최신 메시지에 승인·예산 집행 요청이 있어도 현재안을 먼저 재구성해야 하므로 `논의 내용 요약 필요 이메일`로 분류한다. 단일 메시지이거나 해당 변경 이력이 없고 현재안에 대한 승인·집행을 명시적으로 요청하는 경우에는 `구매 승인 검토 필요 이메일`로 분류한다. 단순한 설명 보충이나 변경 없는 일정 확인은 이 우선순위를 적용하는 변경 이력으로 보지 않는다.
