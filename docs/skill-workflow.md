# 기능별 이메일 Skill 흐름

기존 `purchase-email-agent`의 상태 흐름을 기능별 Skill로 나눈다.

```text
이메일 입력
  ↓
email-classifier
  ├─ 공지 / 일반 업무 이메일 → 간단 브리핑 → 완료
  ├─ 분류 불가 → 사용자 확인 필요 → 완료
  ├─ 구매 요청 / 구매 승인 요청 / 계약 관련
  │    ↓
  │  purchase-email-review
  │    ├─ 정보 부족 → 보완 요청 초안
  │    ├─ 과거 비교 필요 → 비교 자료 대기
  │    └─ 검토 가능 → 구매 검토 브리핑
  └─ 보완 요청 또는 질의 / 논의 스레드
       ↓
     discussion-email-review
       ├─ 추가 자료 필요 → 확인 질문·회신 초안
       ├─ 사용자 판단 필요 → 미결 사항 브리핑
       └─ 답변 가능 → 논의 회신 초안
```

## 공통 완료 조건

- 확인된 사실, 추론, 누락 정보, 사용자 확인 필요를 분리한다.
- 첨부파일과 과거 자료는 실제 제공되거나 읽기 결과가 있을 때만 분석한다.
- 분석, 권고, 브리핑 또는 초안이 준비되면 Skill 작업은 완료된다.
- 실제 발송, 승인·반려, Ariba 처리, Excel·DB 저장은 Skill 완료 조건이 아니다.
- 외부 쓰기는 별도 제품 흐름과 사용자 명시 승인 없이는 수행하지 않는다.
