# 분류 판정 기준

원본은 스토리보드의 회색 스티커 메모다. 기계 판독본은
[`docs/user-flow/criteria.yaml`](../../../docs/user-flow/criteria.yaml)에 있다.
**여기서 기준을 새로 만들지 않는다.** 바꿔야 하면 `criteria.yaml`을 먼저 고친다.

## 판정 순서

위에서부터 확인하고 **먼저 맞는 것에서 멈춘다.** 순서가 곧 우선권이다.

```
1) ariba_approval   승인을 요구하는가?
2) important        사람이 지금 봐야 하는가?
3) discussion       구매 적정성을 논의 중인가?
4) notice           읽고 끝나는가?
5) unknown          위 어디에도 확신이 없다
```

`ariba_approval`이 `important`보다 먼저인 이유: 승인 요청은 그 자체로 처리 경로가 정해져 있고,
"긴급"이라는 수식어는 그 경로 안에서 우선순위로 다뤄지기 때문이다.

## 1. ariba_approval — 구매 승인 요청

**셋 중 하나라도** 해당하면 후보다.

- `Action Required` 키워드
- `승인 요청` / `결재 요청` / `approval request`
- `Ariba` 키워드 (시스템 알림 포함)

후보가 된 뒤 **본문이 실제로 승인·결재 행위를 요구하는지** 확인한다.
Ariba 시스템이 보낸 단순 상태 알림("귀하의 요청이 처리되었습니다")은 `notice`다.

## 2. important — 사용자 확인 중요 이메일

**키워드** (제목 또는 본문 첫 문단)

```
긴급, 중요, ASAP, Immediate, Urgent, 최고 우선, 필독, 즉시,
금일, 오늘까지, 마감, Due Today, Due Tomorrow,
계약, 법무, 소송, 내용증명
```

**발신인**

```
CFO, Finance Boss 1
```

발신인이 위 목록에 있으면 키워드가 없어도 `important`다.

> 스토리보드에 `키워드 더 추가해 주세요` 메모가 붙어 있다. 이 목록은 **미완결**이며
> `criteria.yaml`의 `status: open` 항목이다. 목록에 없다고 해서 중요하지 않다고
> 단정하지 말고, 애매하면 `category_reason`에 판단 근거를 남긴다.

**함정**: 키워드가 있어도 실제 요구 행위가 없으면 `notice`다.
`[필독] 사내 체육대회 안내`는 `notice`다.

## 3. discussion — 논의 이메일

스토리보드 정의 그대로:

> 구매승인 메일(ariba) 및 공지/안내 메일 외의 메일 중 `문의` / `논의` / `견적` 등의
> 키워드를 포함하는 = 즉, **지출결의 전 구매 적정성에 대해 논의하는 부분**

핵심은 **단계**다. 아직 승인 요청 전이고, 무엇을 얼마에 살지 정하는 중이면 `discussion`이다.
공급사 견적 회신, 사양 문의, 가격 협상 스레드가 여기 들어간다.

## 4. notice — 공지/안내

수신자에게 **요구하는 행위가 없는** 메일. 사내 공지, 뉴스레터, 시스템 자동 알림,
읽음 확인만 필요한 안내.

## 5. unknown — 분류 불가

다음 중 하나면 억지로 고르지 말고 `unknown`으로 둔다.

- 서로 다른 라벨의 신호가 정면으로 충돌한다
- 본문이 비어 있거나 잘려서 판단 근거가 없다
- 첨부파일에만 내용이 있는 것으로 보이는데 메타데이터만 주어졌다

`category_reason`에 **무엇과 무엇이 충돌했는지** 구체적으로 적는다.
`unknown`은 실패가 아니라 정직한 답이다. 근거 없이 고른 라벨보다 낫다.

## 경계 사례

| 메일 | 라벨 | 이유 |
| --- | --- | --- |
| `[긴급] 사내 체육대회 참가 신청` | `notice` | 키워드는 있으나 업무 요구 행위가 없다 |
| `Ariba: 귀하의 요청 PR-1042가 승인되었습니다` | `notice` | 결과 알림이지 승인 요청이 아니다 |
| `Re: 서버 증설 견적 3사 비교` | `discussion` | 지출결의 전 단계 |
| CFO 발신 `분기 리뷰 일정 조율` | `important` | 발신인 규칙이 키워드 없이도 걸린다 |
| `[Action Required] PR-1055 결재 요청 (₩12,000,000)` | `ariba_approval` | 승인 요구가 명시적 |
| 본문 비어 있고 제목만 `참고` | `unknown` | 판단 근거 없음 |
