# Ariba 지출결의서 검토 규칙

## 필수 구성항목

### 비용

총액, 통화, 비용 산정 근거 또는 세부 내역을 확인한다. 정책상 필요하다고 입력에 명시된 경우 예산·비용센터도 확인한다. 금액이 서로 충돌하면 `UNCLEAR`이다.

### 예상 정량 효과

매출 증가 또는 비용 감소의 효과 유형, 효과 금액과 통화, 효과 기간 또는 기준 시점, 산출 로직,
주요 가정·기준값·데이터 출처를 모두 확인해야 `SATISFIED`이다. 정성적 표현만 있거나 금액만 있고
계산 근거가 없거나, 입력값 근거 또는 기간이 없으면 충족으로 판단하지 않는다.

### 이전 유사 계약과의 차이

금액, 기간, 범위, 공급업체, 주요 조건의 차이 또는 신규 계약이라는 명시적 설명과 확인 근거가
필요하다. 입력 정보가 불충분한 경우에만 승인된 읽기 전용 계약 조회를 시도한다. 검색 우선순위는
동일 공급업체, 동일 공급업체와 목적·품목, 동일 비용센터·부서와 유사 키워드다. 승인 또는 완료
상태 계약만 후보로 삼는다. 후보가 둘 이상이거나 관련성이 낮거나 조회 권한이 없으면 자동 확정하지
않는다. 조회 실패는 `시스템 연동 없음`으로 기록한다. 찾지 못해도 `이전 계약 없음`으로 추정하지
말고 신규 계약 여부를 질문한다. 조회 결과 사용 시 계약번호, 계약명, 조회 링크, 일치 근거를 기록한다.

### 기본 계약 정보

공급업체명, 계약·구매 목적, 계약 또는 적용 기간, 요청 부서 또는 담당자를 모두 확인한다.

## 상태와 후속 조치

각 항목은 `SATISFIED`, `MISSING`, `UNCLEAR`, `NOT_APPLICABLE` 중 하나다. `NOT_APPLICABLE`은
명시적 근거가 있을 때만 사용한다. 하나라도 `MISSING` 또는 `UNCLEAR`이면
`REQUEST_CLARIFICATION`과 보완 요청 초안을 반환한다. 네 항목이 모두 `SATISFIED`일 때만
`READY_FOR_APPROVAL_REVIEW`와 제공된 승인 URL 안내를 반환한다. URL이 없으면 만들지 않는다.
